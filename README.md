# Doulos Radio PTT

Radio web para voluntarios de Doulos. Usa audio PTT mediante WebRTC/PeerJS y permite micrófono abierto manual.

## Publicación
Conecta este repositorio a Netlify, con directorio de publicación `/` y sin comando de compilación.

## Importante
Prototipo experimental: no está validado para 11–20 usuarios durante 8 horas; puede fallar con pantalla bloqueada o redes móviles restrictivas. Mantener una estación base activa.
